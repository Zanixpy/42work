## Description

**push_swap** is a sorting project. The goal is to sort a list of integers using **two stacks** (A and B) and a limited number of allowed operations.

The program receives numbers as arguments and sorts them in ascending order. The main challenge is to use the fewest possible moves while respecting the rules.

This project focuses on algorithms, stacks, and optimization.

## Instructions

To run the program, first compile it using the Makefile with the command make.
This will generate the binary push_swap.
You can then run it as follows:

./push_swap num1 num2 ...

Example :

./push swap 2 1 3 6 5 8
